ПРАКТИЧЕСКАЯ РАБОТА «МОДЕЛИ ДАННЫХ DJANGO» — КАК ЗАПУСТИТЬ И ПОКАЗАТЬ

1. ПОДКЛЮЧИТЬ PYTHON К ПРОЕКТУ (один раз)
   Внизу справа в PyCharm написано <No interpreter> -> нажать ->
   Add New Interpreter -> Add Local Interpreter -> Virtualenv (Generate new) ->
   Base python: выбрать Python 3.x -> OK.
   Потом закрыть вкладку Terminal (крестик) и открыть заново:
   в начале строки должно появиться (.venv).
   Если в списке нет ни одного Python — установить с python.org
   (при установке поставить галочку «Add python.exe to PATH»).

2. УСТАНОВИТЬ ПАКЕТЫ (один раз), в терминале PyCharm:
       pip install -r requirements.txt

3. ЗАПУСК САЙТА:
       python manage.py runserver
   или двойной клик по run.bat. Сайт: http://127.0.0.1:8005/
