# Web_1_models — модели данных Django

Учебный проект по книге А. В. Постолита «Python, Django и PyCharm для начинающих»
(глава 7 «Модели данных Django», глава 11 «Публикация сайта в сети Интернет»).

Сайт «Список клиентов»: добавление, просмотр, изменение и удаление клиентов в базе данных.

Автор: Кумарбек Ернар, группа КВТ-23-9, Колледж АУЭС.

## Запуск на своем компьютере

    pip install -r requirements.txt
    python manage.py migrate
    python manage.py runserver
